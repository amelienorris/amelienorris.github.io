The problem

Older adults get stuck on everyday sites: refilling a prescription, joining a video call. A chatbot can explain the steps, but they still have to find each button.

JustAsk puts a glowing box around the one thing to use next and says one short line out loud. The person always does the clicking. A caregiver can send tasks from a web app and hear when they are done, with consent.

How it works

  1. They press one button and say what they want.

    Speech goes to text through Cartesia. The request is something like "help me refill my prescription".

  2. JustAsk reads the page and numbers what it sees.

    The content script lists the buttons, links, and fields on screen and gives each a number. Field values are never copied.

  3. Claude picks one number and writes one line.

    Claude gets the request, the steps so far, and the numbered list, and returns one element number plus a short instruction. Code then checks the number exists and runs the safety gates.

  4. A highlight ring moves to the next thing to click.

    The ring pulses around that element and the line is spoken and shown as a large caption.

  5. They click. JustAsk never clicks for them.

    Their click moves it to the next step until the task is done.

  6. The caregiver dashboard mirrors progress.

    If the person has agreed, the caregiver app shows the task moving and gets a note when it is finished.
