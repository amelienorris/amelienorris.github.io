The problem

Applying to jobs means filling the same fields on dozens of different sites. kawbs started as Amelie’s personal tool for that and grew into a product other people used.

kawbs discovers jobs, drafts application materials, fills forms, and tracks applications. It is on hold.

How it works

  1. A request leaves the browser.

    Users reach kawbs at its own domain, which Amelie bought and set up.

  2. Caddy terminates TLS and proxies the request.

    Caddy sits in front of everything on the DigitalOcean box. It handles HTTPS certificates and routes each request to the right container.

  3. Docker Compose runs the app services.

    Docker Compose runs the api, db, and caddy services. FastAPI serves the React frontend and application API.

  4. The service reads and writes the database.

    The API reads and writes PostgreSQL, running in the db service on the same DigitalOcean host.

  5. The response travels back the same way.

    The reply goes back through Caddy over TLS to the browser.

My part

Team: Solo

  • Bought and set up the hosting, domain, and database
  • Runs the stack on DigitalOcean with Caddy and Docker Compose
  • Diagnosed a container memory issue and a local DNS caching issue
